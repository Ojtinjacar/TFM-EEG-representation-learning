# CL-DaSCI-CIMCYC

Representation learning on Developmental Infant EEG. A collaboration between [DaSCI](https://dasci.es/) and [CIMCYC](https://cimcyc.ugr.es/).

## Overview

The pipeline preprocesses multi-session infant EEG recordings (EEGLAB `.set` files), trains self-supervised backbones (SimCLR, Autoencoder, Masked Autoencoder, Triplet Loss), and evaluates the learned representations on downstream regression tasks (age prediction, IQ estimation) via linear probing or fine-tuning. Classical baselines (PCA, FOOOF spectral descriptors, ST-EEGFormer) are included for comparison.

## Setup

### 1. Clone the repository

```bash
git clone <repo-url>
cd RL-DaSCI-CIMCYC-C
```

### 2. Create and activate the conda environment

```bash
conda env create -f environment.yml   # creates env named "dasci-cimcyc"
conda activate dasci-cimcyc
```

Key packages included: `python=3.11`, `pytorch=2.5.1` (CUDA 11.8), `mne=1.9`, `scikit-learn=1.6`, `numpy=2.0`, `pandas=2.2`, `matplotlib=3.10`, `seaborn=0.13`, `specparam=2.0` (FOOOF), `timm=1.0`.

### 3. Create output directories

All scripts must be run from the **repository root** so that relative paths (`data/`, `save/`, `src/`) resolve correctly.

```bash
mkdir -p save/models save/figures/pretrain save/figures/prediction save/downstream_results
```

## Step 1 — Raw extraction (one-time)

Convert EEGLAB `.set` files (placed in `data/original/raw/`) into a single NumPy array and metadata CSV.

```bash
python src/preprocessing.py
```

Outputs written to the current directory:
- `all_epochs_raw.npy`
- `all_epochs_metadata.csv`
- `channel_names.txt`

Move them to `data/raw/` before continuing.

---

## Step 2 — Postprocessing

Filter by brain region and frequency band, apply per-channel z-score normalisation, and cut into fixed-length windows (default 5 s at 250 Hz = 1 250 samples).

```bash
python src/postprocessing.py \
    --data_path    data/raw/all_epochs_raw.npy \
    --meta_path    data/raw/all_epochs_metadata.csv \
    --socio_path   data/raw/metadata.csv \
    --channels_txt data/raw/channel_names.txt \
    --zones frontal central parietal occipital \
    --l_freq 0.2 --h_freq 48.0 \
    --seconds 5.0 \
    --output_path  data/processed/5_s
```

| Argument | Description | Default |
|---|---|---|
| `--zones` | Brain regions to keep (`frontal`, `central`, `parietal`, `occipital`). Omit for all 124 channels. | — |
| `--l_freq` / `--h_freq` | Bandpass filter edges (Hz) | `0.2` / `48.0` |
| `--seconds` | Window duration (s) | `5.0` |
| `--output_path` | Where to save `.npy` + `.csv` | `data/processed/5_s` |

Outputs: `processed_windows.npy` (N, C, 1250) and `processed_metadata.csv`.

## Step 3 — Pre-training

All training scripts share these common arguments:

| Argument | Description |
|---|---|
| `--zone` | Brain region (`all`, `frontal`, `central`, `parietal`, `occipital`) |
| `--frequency` | Frequency band (`all`, `theta`, `alpha`, `beta`, `gamma`) |
| `--exclude_subjects` | Space-separated subject IDs to hold out for test |
| `--fold_id` | Label appended to the saved model filename (e.g., `fold0`) |
| `--data_path` / `--data-path` | Path to `processed_windows.npy` |

### SimCLR

```bash
python src/train_simclr.py \
    --data_path     data/processed/5_s/processed_windows.npy \
    --zone          all \
    --frequency     all \
    --batch_size    512 \
    --lr            1e-3 \
    --weight_decay  1e-4 \
    --temperature   0.05 \
    --num_epochs    100 \
    --save_dir      save/models \
    --plot_dir      save/figures/pretrain \
    --exclude_subjects B010 B011 B014 \
    --fold_id       fold0
```

Saved as: `save/models/SimCLR_<zone>_<frequency>_<fold_id>_batch_512_lr_0.001_wd_0.0001_temperature_0.05.pth`

### Autoencoder

```bash
python src/train_auto.py \
    --data-path     data/processed/5_s/processed_windows.npy \
    --zone          all \
    --frequency     all \
    --hidden-size   128 \
    --epochs        100 \
    --lr            1e-3 \
    --save-model-dir save/models \
    --save-fig-dir   save/figures/pretrain \
    --exclude_subjects B010 B011 B014 \
    --fold_id       fold0
```

Saved as: `save/models/AE_<zone>_<frequency>_<fold_id>_hidden128_e100.pth`

### Masked Autoencoder (MAE)

```bash
python src/train_mae.py \
    --data-path     data/processed/5_s/processed_windows.npy \
    --zone          all \
    --frequency     all \
    --hidden-size   128 \
    --epochs        100 \
    --mask-ratio    0.3 \
    --block-size    25 \
    --save-model-dir save/models \
    --save-fig-dir   save/figures/pretrain \
    --exclude_subjects B010 B011 B014 \
    --fold_id       fold0
```

Saved as: `save/models/MAE_<zone>_<frequency>_<fold_id>_hidden128_mask30_block25_e100.pth`

### Triplet Loss

```bash
python src/train_triplet_loss.py \
    --data_path    data/processed/5_s \
    --target       age \
    --zone         all \
    --frequency    all \
    --embedding_size 128 \
    --margin       0.4 \
    --num_epochs   200 \
    --save_dir     save/models \
    --plot_dir     save/figures/pretrain \
    --exclude_subjects B010 B011 B014 \
    --fold_id      fold0
```

`--target` accepts `age` or `cit_36mo`.

Saved as: `save/models/Triplet_<target>_<zone>_<frequency>_<fold_id>_emb128_m0.4.pth`

## Step 4 — Downstream evaluation

Evaluate a pre-trained backbone (or a baseline) on a regression task using a subject-based train/test split.

```bash
python src/downstream.py \
    --data_path  data/processed/5_s/processed_windows.npy \
    --meta_path  data/processed/5_s/processed_metadata.csv \
    --model_path save/models/SimCLR_all_all_fold0_batch_512_lr_0.001_wd_0.0001_temperature_0.05.pth \
    --method     SimCLR \
    --zone       all \
    --frequency  all \
    --target     age \
    --eval_mode  linear_probe \
    --test_subjects B010 B011 B014 \
    --plot_dir   save/figures/prediction \
    --save_dir   save/models
```

| Argument | Options / Notes |
|---|---|
| `--method` | `SimCLR`, `AE`, `MAE`, `TripletLoss`, `PCA`, `supervised` |
| `--target` | `age` (months) · `cit_36mo` (Composite IQ at 36 mo) |
| `--eval_mode` | `linear_probe` (frozen backbone) · `fine_tuning` (full model) |
| `--model_path` | Required for all methods except `PCA` and `supervised` |

Metrics reported: per-window MSE/RMSE/R² and subject-averaged nRMSE/R².

**PCA baseline** (no `--model_path` needed):

```bash
python src/downstream.py \
    --data_path data/processed/5_s/processed_windows.npy \
    --meta_path data/processed/5_s/processed_metadata.csv \
    --method    PCA \
    --zone      all \
    --frequency all \
    --target    age \
    --test_subjects B010 B011 B014
```

**Supervised baseline** (trains from scratch):

```bash
python src/downstream.py \
    --data_path data/processed/5_s/processed_windows.npy \
    --meta_path data/processed/5_s/processed_metadata.csv \
    --method    supervised \
    --zone      all \
    --frequency all \
    --target    age \
    --test_subjects B010 B011 B014
```

## Step 5 — Cross-validation

`run_downstream.py` automates K-fold or leave-one-out CV. For each fold it pre-trains all backbones, then evaluates every method × target × eval-mode combination.

### K-fold (single node)

```bash
python run_downstream.py \
    --cv_strategy kfold \
    --n_folds     10 \
    --targets     age cit_36mo \
    --eval_modes  linear_probe fine_tuning \
    --zone        all \
    --frequency   all \
    --meta_path   data/processed/5_s/processed_metadata.csv \
    --save_dir    save/downstream_results
```

### K-fold parallelised across 5 SLURM nodes (2 folds each)

| Node | Command |
|---|---|
| 1 | `python run_downstream.py --cv_strategy kfold --n_folds 10 --fold_range 0 2 --targets age cit_36mo --eval_modes linear_probe fine_tuning` |
| 2 | `python run_downstream.py --cv_strategy kfold --n_folds 10 --fold_range 2 4 --targets age cit_36mo --eval_modes linear_probe fine_tuning` |
| 3 | `python run_downstream.py --cv_strategy kfold --n_folds 10 --fold_range 4 6 --targets age cit_36mo --eval_modes linear_probe fine_tuning` |
| 4 | `python run_downstream.py --cv_strategy kfold --n_folds 10 --fold_range 6 8 --targets age cit_36mo --eval_modes linear_probe fine_tuning` |
| 5 | `python run_downstream.py --cv_strategy kfold --n_folds 10 --fold_range 8 10 --targets age cit_36mo --eval_modes linear_probe fine_tuning` |

Add `--zone all --frequency all --meta_path data/processed/5_s/processed_metadata.csv --save_dir save/downstream_results` to every node command (or set them in `run.sh`).

### Leave-one-out

```bash
# Run all LOO folds in one go
python run_downstream.py \
    --cv_strategy leave_one_out \
    --targets     age cit_36mo \
    --eval_modes  linear_probe fine_tuning \
    --zone        all \
    --frequency   all \
    --meta_path   data/processed/5_s/processed_metadata.csv \
    --save_dir    save/downstream_results
```

Parallelise by subject range with `--fold_ranges`:

```bash
# Node processes age folds 0-9 and cit_36mo folds 0-9
python run_downstream.py \
    --cv_strategy leave_one_out \
    --fold_ranges age:0:10 cit_36mo:0:10 \
    --targets     age cit_36mo \
    --eval_modes  linear_probe \
    --zone        all \
    --frequency   all \
    --meta_path   data/processed/5_s/processed_metadata.csv \
    --save_dir    save/downstream_results
```

Add `--no_skip` to force re-training even if a model checkpoint already exists.

### Aggregate parallel results

After all nodes finish, merge the partial CSVs:

```bash
# K-fold
python aggregate_results.py \
    --input_pattern "save/downstream_results/downstream_raw_results_kfold_folds*.csv" \
    --output_dir    save/downstream_results \
    --cv_strategy   kfold

# Leave-one-out
python aggregate_results.py \
    --input_pattern "save/downstream_results/downstream_raw_results_leave_one_out_*.csv" \
    --output_dir    save/downstream_results \
    --cv_strategy   leave_one_out
```
